# Script-de-respaldo
Script que sirve para hacer respaldo de las carpetas principales de la pc/laptop,


- Debe Respaldar archivos de las carpetas Documentos, Escritorio(Obligatorio) además de preguntar al que ejecuta el script si existe algún otro disco (D:, E:, F:, etc) y preguntar si desea respaldar la carpeta de Descargas, Música, Imágenes y Video
- Debe guardar el nombre del quipo
- El script debe mandar todo ese respaldo a una dirección IP de un servidor y preguntar por la IP en caso de que el usuario lo desee; de lo contrario se le preguntará si se guardará en un almacenamiento externo
